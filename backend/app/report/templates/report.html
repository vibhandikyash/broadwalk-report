How to Read These Working Papers

{{ head|upper }}SOURCE PROVENANCE METHOD

Each data-sources sheet states, for every figure on the page before it, how that figure was obtained. This page defines the seven markers it uses and the arithmetic conventions applied throughout the report.

How we got itThe seven markers used on every data-sources sheet
ExtractedRead directly from a supplied file. The sheet names the file, the worksheet or page, the row, and quotes the source line it was read from.
InferredInterpreted from a source value whose original label differs from the report field. The source label and inference are shown for review.
Extracted by OCRThe page carried no machine-readable text, so it was transcribed from an image by vision OCR before being read. Transcription confidence is stated. These warrant a closer look than the rest.
CalculatedDerived from other figures in this report. The sheet gives the formula in full, with each input value and the file and row it came from.
Entered by reviewerTyped on the review screen, either because no file carried it or because the extracted value was corrected.
AI-writtenNarrative prose drafted from the figures above it, for a reviewer to check. No number is ever produced this way.
Not foundIn none of the files supplied for this period. The sheet names the document that would ordinarily carry it. Nothing is estimated or inferred to fill the gap.
Calculation conventionsApplied to every calculated figure
PrecisionEvery calculation runs at full precision on the extracted values and is rounded once, for display only. An intermediate result is never rounded and fed into the next step.
RoundingHalf away from zero: 1,424.5 prints as 1,425 and {{ MINUS }}162.5 as {{ MINUS }}163. This is the convention of financial statements and of Excel’s ROUND, rather than the half-to-even default of most programming languages.
Percentage changeDivided by the prior-period value, never by the current one.
VarianceActual less budget. On expense lines the sign is inverted so that a favourable result reads positive; the data-sources sheet says so against each line it applies to.
Reading a differenceBecause operands are rounded for display only, a printed difference can differ by one unit from subtracting the two printed figures. Where they differ, the printed difference is the more accurate of the two.
